# Dumaloq TG

Telegram-бот: отправляешь видео — получаешь круглое видеосообщение.
Разработка и пробный запуск — через браузер, без скачивания проекта на компьютер.

## Как работает

1. Принимает обычное видео или видеофайл в личном чате.
2. Проверяет длительность и размер, обрезает прямоугольный кадр до квадрата по центру.
3. Создаёт MP4 640 × 640: H.264, yuv420p, 30 fps, AAC при наличии звука.
4. Отправляет через Telegram Bot API методом `sendVideoNote`.
5. Удаляет временные файлы.

Круг отображает Telegram; сам видеофайл остаётся квадратным. Углы не видны, поэтому лицо и важные надписи должны находиться ближе к центру. Немое видео поддерживается.

## Команды

| Команда | Действие |
| --- | --- |
| `/start`, `/help` | Инструкция |
| `/trim` | Первые 60 секунд, режим по умолчанию |
| `/split` | Несколько кружков по 60 секунд плюс остаток |
| `/id` | Ваш числовой Telegram ID |

Режим выбирается **до отправки** видео и сохраняется до перезапуска процесса.

## Первый запуск полностью в браузере

### 1. Создать бота в Telegram

Откройте проверенного [@BotFather](https://t.me/BotFather), выполните `/newbot`, задайте имя и username с окончанием `bot`. Сохраните токен.

### 2. Добавить токен в Codespaces secrets

Откройте [личные настройки Codespaces](https://github.com/settings/codespaces):

- **New secret**
- Name: `BOT_TOKEN`
- Value: токен, полученный у BotFather
- Repository access: `khdjkbr/dumaloq-tg`

Токен должен находиться в **Codespaces secrets**. Не добавляйте его в файлы, коммиты, Issues или переписку.

### 3. Открыть Codespaces

На странице репозитория нажмите **Code → Codespaces → Create codespace on main**.

Конфигурация `.devcontainer` использует готовый образ Microsoft Universal и запускает `scripts/setup.sh`: он устанавливает FFmpeg и библиотеки в изолированную `.venv`. На компьютер ничего устанавливать не требуется. Дождитесь завершения настройки.

Codespaces использует квоту вашего GitHub-аккаунта. Перед запуском проверьте доступность и лимиты в настройках Billing; платный режим для теста включать не требуется.

### 4. Запустить бота

В терминале браузерного редактора:

```sh
bash scripts/start.sh
```

Если секрет добавлен после создания Codespace, остановите и повторно запустите Codespace, чтобы переменная появилась в окружении. Запускайте один экземпляр бота на один токен.

В Telegram откройте своего бота, нажмите **Start** и отправьте квадратное видео на 5–10 секунд.

Для проверки разбиения выберите `/split`, затем отправьте видео на 65 секунд: должны прийти два кружка.

Codespaces подходит для разработки и пробного запуска. При остановке среды бот прекращает работу. Постоянное размещение на сервере настраивается отдельным этапом; GitHub Actions выполняет только проверки.

## Если Codespace открылся в recovery mode

Ошибка `No module named 'aiogram'` означает, что установка библиотек не выполнилась или используется другой Python.

В терминале уже открытого Codespace выполните:

```sh
git pull --ff-only
bash scripts/start.sh
```

Скрипт установит недостающие зависимости и FFmpeg, затем запустит бота через Python из `.venv`. Он не выводит токен. При успешной проверке Telegram появится ссылка на вашего бота.

Чтобы повторно создать основную среду с исправленной конфигурацией, откройте палитру **Ctrl+Shift+P → Codespaces: Rebuild Container** после обновления репозитория.

Точная причина исходного сбоя сборки определяется по **Codespaces: View Creation Log**; один только recovery mode не указывает конкретную причину.

## Ограничения MVP

- Исходник до **20 000 000 байт**, длительность до **10 минут**.
- Только личные сообщения.
- Одно активное задание на пользователя; один обработчик и до 8 заданий в очереди.
- Очередь и настройки в памяти; после перезапуска незавершённое видео нужно отправить снова.
- При частичной отправке бот сообщает число отправленных кружков. Автоматических повторов отправки нет, чтобы не создавать дубликаты при сетевой неопределённости.
- При штатном завершении задания временные файлы удаляются. После аварийного завершения системы могут остаться каталоги `dumaloq-*` в системной временной папке.
- Пока не реализованы Local Bot API Server для больших исходников, отслеживание лица и постоянная очередь.

## Дополнительные переменные окружения

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `BOT_TOKEN` | обязательна | Токен Telegram-бота |
| `ALLOWED_USER_IDS` | пусто | Разрешённые числовые ID через запятую; пусто — все пользователи |
| `FFMPEG_BIN` | `ffmpeg` | Исполняемый файл FFmpeg |
| `FFPROBE_BIN` | `ffprobe` | Исполняемый файл FFprobe |

`ALLOWED_USER_IDS` тоже можно добавить в Codespaces secrets. Узнать свой ID можно командой `/id` до включения ограничения.

Для отдельного хостинга есть `Dockerfile`. Он принимает перечисленные переменные окружения и запускает `python bot.py`. Входящие порты и публичный домен для long polling не нужны. Уже установленный webhook автоматически не удаляется: используйте новый бот или отключите предыдущую интеграцию.

## Автоматические проверки

GitHub Actions устанавливает зависимости и FFmpeg, проверяет импорт приложения, логику разбиения, обработчики Telegram с имитацией API, ошибки и таймауты. Реальные тестовые видео генерируются прямо в CI, конвертируются, затем проверяются FFprobe. Пользовательские ролики и настоящий Telegram-токен для CI не нужны.

Результаты доступны во вкладке [Actions](https://github.com/khdjkbr/dumaloq-tg/actions) и в pull request.

Запуск тестов в терминале Codespaces:

```sh
 .venv/bin/python -m unittest discover -s tests -v
```

Доставка настоящего кружка в Telegram проверяется отдельно после подключения `BOT_TOKEN`.
